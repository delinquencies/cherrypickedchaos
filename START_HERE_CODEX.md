# Open Cherry Picked Chaos in ChatGPT desktop / Codex

1. Extract this ZIP into your own project folder on your computer (for example `Documents/Cherry-Picked-Chaos`).
2. Open the **ChatGPT desktop app** and choose **Codex** from the app menu.
3. Select **Add new project** or **Open folder** (labels may vary by version), and choose the extracted folder that contains `index.html` and `AGENTS.md`.
4. Start a Codex chat with **Work in > This computer / Local** selected. Keep approval prompts enabled initially.
5. Say: "Read AGENTS.md and START_HERE_CODEX.md. Audit this Cherry Picked Chaos site without changing files yet. Then launch a local preview, identify specific improvements, and propose how to use assets/illustrated_storefront_concept.png without misrepresenting the building."

Important: Opening only the ZIP is not the same as opening its extracted project folder.

This folder contains the latest retro v2 website, the illustrated storefront asset, screenshots, and the original Google Stitch export. The illustrated storefront image is an idealized illustration (includes a sign that has NOT been confirmed to exist).

The site is a static HTML/CSS/JS prototype: opening `index.html` in a browser is sufficient for basic inspection. Codex can choose a local preview server for development/testing.
